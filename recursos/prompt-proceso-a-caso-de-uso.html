Prompt: de un proceso de tu área a un caso de uso de IA

Describe un proceso tal como lo hacen hoy y obtén dónde ayuda la IA, dónde no y cómo probarlo.

ParaTransformación e innovación · Personas y RR. HH.
Tiempo15 minutos
HerramientaCualquier IA

Para qué sirve

Pasar de “deberíamos usar IA” a un caso concreto que se puede probar la próxima semana.

Qué necesitas

Un proceso que tu equipo repite cada semana, descrito paso a paso. Sin datos personales.

El prompt

Cambia lo que está entre [corchetes]
Actúa como consultor de procesos con experiencia en IA generativa.

Este es un proceso de mi área, tal como lo hacemos hoy:
[describe los pasos, quién los hace y cuánto tiempo toma cada uno]

1) Marca en qué pasos la IA puede ayudar (y cómo), en cuáles no conviene y por qué.
2) Propón UN caso de uso para probar la próxima semana: qué se le pide a la IA, quién revisa el resultado y cómo medimos si sirvió.
3) Escribe el prompt que usaría la persona del equipo para ese caso.
4) Dime qué riesgo hay con los datos de este proceso y cómo evitarlo.

No inventes tiempos ni cifras: si no te los di, pregúntamelos.

Lo que te devuelve (resumen)

El proceso con los pasos marcados, un caso de uso listo para probar, el prompt para el equipo y el cuidado con los datos.

Mi criterio

El mejor primer caso es aburrido: una tarea repetitiva que el equipo odia. Si el primer caso es espectacular, suele ser difícil de sostener.
